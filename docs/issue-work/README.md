## Problems found but not fixed

From the reviews and from writing the design document. Details are in `reports/` and in each design part's "Open points".

- **Security:** the local server has no access token or Origin/Host check, and its path checks differ between routes.
- **Sidecar:** once a read-only folder becomes writable again, its `photoinfo.json` can keep the absolute folder path from the fallback file.
- **Tagging:**
  - model downloads aren't covered by the network guard;
  - worker requests have no timeout;
  - failed photos are never retried;
  - Settings accepts a partly downloaded model.
- **Clean-up:** old catalogue rows and decoded HEIC copies are never removed.
- **Minors** deferred by each review are listed in `reports/*-review.md`. Examples:
  - a Regenerate can take up to 60 s to reach the album file;
  - the preview step is 18–25 ms, a little over one frame;
  - the editor's export falls back to sharp-by-path;
  - the `?` list still says Ctrl+C copies "several as files" on Linux.
